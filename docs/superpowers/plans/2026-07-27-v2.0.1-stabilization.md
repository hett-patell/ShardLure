# ShardLure v2.0.1 Stabilization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Correct every confirmed v2.0.0 security, evidence-integrity, ingestion, frontend-state, parser, accessibility, installer, and release-hygiene defect and publish the verified result as v2.0.1.

**Architecture:** Preserve the single-process Go/SQLite design, but move evidence capture behind one bounded worker, make retry and retention state durable, reconcile late Cowrie session identity transactionally, and fail closed whenever an unauthenticated listener is not provably loopback. Browser authentication moves from persistent query strings to a short query bootstrap that creates an HttpOnly session cookie and redirects to a clean URL; shared appearance state owns the theme/mode tuple.

**Tech Stack:** Go, modernc SQLite, vanilla HTML/CSS/JavaScript, embedded web assets, Python release-contract tests, shell installers, GitHub Actions.

## Release-wide invariants

- Production behavior changes follow red/green/refactor: add a focused regression test, observe the expected failure, implement the smallest fix, and rerun the affected package.
- `fetched` and policy `blocked` artifacts are terminal. Transport errors, HTTP 5xx, cancellation, and expired `capturing` leases are retryable.
- Artifact files are content addressed. Retention may unlink a path only after deleting expired rows and proving no live row references that path while the store write lock is still held.
- Tokenless listeners may bind only literal or resolved loopback addresses. Wildcards, unresolved hostnames, and public addresses fail startup.
- Browser tokens do not remain in URLs, history, navigation links, or referrers. A valid `?token=` on a page request is bootstrap-only: set an HttpOnly, SameSite=Strict cookie and redirect to the same URL without the token.
- Cowrie events for one session converge on `cowrie:<hassh>` even when `client.kex` arrives after earlier events were committed.
- Session side tables carry an observation timestamp and participate in normal retention.
- All dynamic `href` values pass through the same HTTP(S)-only sanitizer.
- Signal appearance identity is `(theme, mode)`; either component changing triggers persistence, broadcast, and visualization invalidation.
